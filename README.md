# Briaton — Lamps Online Store

An interactive e-commerce website for a lighting brand, featuring a dynamic product catalog and shopping cart.

## About the Project

Briaton is an online store for lighting systems developed as a final project during my frontend development training at Skillbox. I implemented the entire JavaScript functionality using pre-built HTML markup and CSS styles.

## Features

- Dynamic product rendering from JSON data
- Product filtering by type and availability
- Sorting products by price and popularity
- Pagination
- Shopping cart functionality
- Interactive catalog menu and city selection
- Product availability tooltips
- FAQ accordion
- Product slider powered by Swiper.js
- Form validation using Just Validate
- Asynchronous form submission using Fetch API

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- JSON
- Fetch API
- Swiper.js
- Just Validate

## Key Skills Demonstrated

- DOM manipulation and event handling
- Working with structured data
- Implementing filtering and sorting logic
- Managing shopping cart interactions
- Form validation and asynchronous requests
- Integrating third-party JavaScript libraries

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/lusine16/lamps-online-store.git
   ```

2. Navigate to the project directory:

   ```bash
   cd lamps-online-store
   ```

3. Open `catalog.html` in your browser or use the Live Server extension in VS Code.
